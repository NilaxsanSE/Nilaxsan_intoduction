# Nilaxsan Video Introduction

Premium personal video introduction landing page for Suvendralingam Nilaxsan, built for sharing with international recruiters.

## Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- Lucide React
- Framer Motion

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Vercel Deployment

Deploy the repository as a Vite project on Vercel. The introduction video is served from `public/media/IMG_6927.mp4`, so it is included in the production build output automatically.
